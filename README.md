
# SafeHaven
### Community Disaster Preparedness and Emergency Response Management System

## Project Description

SafeHaven is a web-based disaster preparedness and emergency response management system designed to help communities organize resident information, monitor disaster incidents, manage evacuation centers, coordinate rescue teams, and track emergency resources.

The system also integrates weather monitoring and interactive emergency mapping to support disaster preparedness and response activities.

## Features

- **Resident Management** – Manage resident information and records.
- **Disaster Type Management** – Maintain different disaster categories.
- **Incident Management** – Record and monitor reported disaster incidents.
- **Evacuation Center Management** – Manage evacuation center information and capacity.
- **Rescue Team Management** – Organize rescue teams and monitor their availability.
- **Response Management** – Assign rescue teams to reported incidents.
- **Resource Management** – Monitor available emergency supplies and resources.
- **Weather Monitoring** – Display current weather information using OpenWeatherMap.
- **Emergency Mapping** – Visualize incidents and evacuation centers using an interactive map.
- **RESTful API** – Provide API endpoints for the system's data.
- **Sample Data Generation** – Generate sample records using Faker.
